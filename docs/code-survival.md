# Precursor Code Survival Map v0.1

Sarmady is a convergence project, not a repository merge. A precursor mechanism survives only when it fits the canonical ontology and preserves the constitution.

## Alsoul

**Port/generalize:** authority/action/effect/reconciliation semantics; immutable domain/result contracts; context snapshot/frontier ideas; memory proposal/admission concurrency tests; recovery-boundary tests; action-bound approval tests; execution-fence tests; UNKNOWN_EFFECT / NO_EFFECT tests; presentation-truth tests.

**Rewrite:** companion-specific identity into generic Person/Agent/Principal; personal-calendar action models into generic action contracts; configured/calendar runtimes into generic runtime adapters.

**Mine, do not transplant:** large calendar-specific service modules. Extract algorithms and invariants rather than carrying vertical-specific structure into the kernel.

**Retire from Sarmady core:** exact regex interaction grammars, local UI/browser surface, and historical schema migration chain. They remain useful research artifacts in Alsoul.

## Durable Infinite Context

**Port/adapt:** evidence/claim/relation primitives; bitemporal semantics; transactional current-head materialization; normalized membership/selective materialization; dependency-aware invalidation; maintenance/recovery journal; snapshot/stale-read fencing where dependencies are unaffected.

**Keep as evaluation:** normalized-membership/locality experiments and bounded-context experiments.

**Quarantine as storage research:** later fixed-page, cuckoo/hash, radix, reclamation, and other experimental index families until they beat the simpler production candidate under Sarmady workloads.

## Ola / Moneta

**Port/translate:** memory lifecycle event model; seen-vs-used telemetry; use-driven consolidation semantics; archive/restore/tombstone/delete workflow; audit events.

**Keep behind policy interfaces:** Ebbinghaus-style memory strength, decay constants, consolidation thresholds, and auto-archive suggestions. They are hypotheses, not ontology.

**Retire from Sarmady core:** ZCode/transcript hooks, MCP host wiring, migration scripts, and deployment-specific JavaScript glue.

## Reasoning Engine

**Port:** COMPACT and FULL reasoning policies as versioned cognitive policies; strict protocol/outcome evaluation dimensions; blinded pairwise evaluation methodology; prompt hashing, replicates, frozen-suite metadata, and evaluator-independence checks.

**Evaluation/archive:** existing exposed benchmark cases remain regression suites, not fresh holdouts.

**Quarantine:** DIRECT/COMPACT/FULL adaptive routing until it demonstrates reliable value under independent validation.

**Rewrite:** provider-specific OpenAI/Z.AI plumbing against Sarmady's shared model adapter interface.

## Rule of precedence

When precursor code conflicts with Sarmady's constitution, the constitution wins. Preserve validated semantics and tests more aggressively than package structure.
